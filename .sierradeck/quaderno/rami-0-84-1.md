**Trappola dei conflitti in `lista-lavori.md` (22/10, c-79).** Il file ha i fine
riga di Windows (CRLF). Uno script che divide le righe con `'\n'` lascia `\r` in
coda e non riconosce più `=======`. Se poi nella stessa riga di comando c'è un
`git add && git commit` dopo un `;`, il commit parte con i segni del conflitto
dentro (successo con l'unione di c-81, rimediato in `d3422c12`). Due regole:
dividere con `/\r?\n/`, e prima di ogni commit controllare
`grep -c "^<<<<<<<" lista-lavori.md` = 0.
